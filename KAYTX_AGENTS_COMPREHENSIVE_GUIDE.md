### Department Cost Structure

Each department has two types of costs:

**1. One-Time Activation Cost**
- Paid once when activating a department
- Range: $50 - $200 depending on complexity
- Covers initial setup and configuration

**2. Monthly Maintenance Cost**
- Recurring monthly fee
- Range: $25 - $100 depending on complexity
- Covers ongoing maintenance and updates

**3. Agent Multiplier**
- Applied to token costs based on department complexity
- Range: 1.0x - 2.5x
- More complex departments have higher multipliers

### Cost Calculation Formula

```
Total Monthly Cost = Base Fee
                   + Σ(Department Activation Costs)
                   + Σ(Department Maintenance Costs)
                   + Token Costs
                   + Cloud Infrastructure Costs

Where:
Token Costs = Σ(Agent Token Usage × Token Price × Agent Multiplier)

Cloud Costs = (Compute Hours × Compute Price)
            + (Storage GB × Storage Price)
            + (Network GB × Network Price)
```

## 🔤 Token Usage System

### What Are Tokens?
- **Tokens** are units of text processed by AI models
- **1,000 tokens ≈ 750 words** (roughly 1 page of text)
- Counted for both input (prompts) and output (responses)
- The primary metric for AI usage billing

### Token Metrics Tracked

1. **Input Tokens** - Tokens sent to the AI model (prompts, context)
2. **Output Tokens** - Tokens generated by the AI model (responses)
3. **Cached Tokens** - Tokens served from cache (no additional cost)
4. **Total Tokens** - Sum of all tokens processed
5. **Average Tokens per Request** - Efficiency metric
6. **Cache Hit Rate** - Percentage of requests served from cache

### Real-Time Monitoring Dashboard

The system provides live monitoring of:
- **Active Agents** - Number of agents currently executing
- **Tokens Last Hour** - Token consumption in the last hour
- **Tokens Last Day** - Token consumption in the last 24 hours
- **Estimated Daily Cost** - Projected daily cost based on usage
- **Top Consumers** - Agents with highest token usage
- **Budget Status** - Current spend vs. budget limits

## 💡 Cost Saving Strategies

### 1. Selective Department Activation
**Savings: 50-90%**

Only activate departments you actually need:
- Start with 2-3 core departments
- Activate 10-20 essential agents
- Scale up as business grows

**Example:**
- Full activation: 22 departments × $100 avg = $2,200/month
- Selective activation: 3 departments × $100 avg = $300/month
- **Savings: $1,900/month (86%)**

### 2. Response Caching
**Savings: 15-25%**

Enable caching for frequently asked questions:
- Cache common responses
- Set appropriate TTL (time-to-live)
- Monitor cache hit rate

**Example:**
- Without caching: 1M tokens/day × $0.50 = $500/month
- With 20% cache hit rate: 800K tokens/day × $0.50 = $400/month
- **Savings: $100/month (20%)**

### 3. Prompt Optimization
**Savings: 10-20%**

Optimize prompts to reduce token usage:
- Keep prompts concise
- Use system prompts effectively
- Remove redundant information

**Example:**
- Unoptimized: 2,000 tokens/request × 1,000 requests = 2M tokens
- Optimized: 1,500 tokens/request × 1,000 requests = 1.5M tokens
- **Savings: 500K tokens (25%)**

### 4. Agent Deactivation
**Savings: $10-50 per agent**

Deactivate low-usage agents:
- Review agent usage monthly
- Deactivate agents with <10 uses/month
- Reactivate only when needed

**Example:**
- 50 inactive agents × $20/month = $1,000/month savings

### 5. Tier Optimization
**Savings: Variable**

Choose appropriate tier based on usage:
- Start with Standard tier
- Upgrade to Premium when exceeding 10 agents or 10M tokens
- Upgrade to Enterprise when exceeding 50 agents or 100M tokens

**Example:**
- Startup using Premium: $499/month for 5 agents
- Switch to Standard: $99/month for same usage
- **Savings: $400/month**
