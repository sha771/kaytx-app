# Cloud AI Agent Cost & Token Usage Guide

## Overview

This guide explains the complete cost and token usage tracking system for AI agents running on cloud infrastructure. Companies can activate departments and their required agents, with comprehensive monitoring and billing.

---

## System Architecture

### 1. Cost Tracking Service
**Location:** `backend/services/agent-cost-tracking-service.ts`

Tracks all costs associated with AI agent execution including:
- Token usage costs (input/output tokens)
- Cloud infrastructure costs (compute, storage, network)
- Department activation costs
- Agent-specific cost metrics

### 2. Token Usage Monitoring Service
**Location:** `backend/services/token-usage-monitoring-service.ts`

Real-time monitoring and analytics for token consumption:
- Per-agent token tracking
- Department-level aggregation
- Company-wide analytics
- Budget alerts and optimization suggestions

### 3. UI Components
- **AgentCostDashboard** - Real-time cost and token visualization
- **DepartmentActivationCost** - Department activation pricing and cost projection

## Cost Calculation Formula

### Total Cost per Agent Execution

```
Total Cost = Token Cost + Compute Cost + Storage Cost + Network Cost

Where:
Token Cost = (Input Tokens / 1,000,000) × Input Token Price
           + (Output Tokens / 1,000,000) × Output Token Price
           × Agent Multiplier

Compute Cost = (Execution Time in Hours) × Compute Price

Storage Cost = Storage Used (GB) × Storage Price

Network Cost = Network Transferred (GB) × Network Price
```

### Monthly Company Cost

```
Monthly Cost = Base Fee
             + Σ(Department Activation Costs)
             + Σ(Department Maintenance Costs)
             + Token Costs
             + Cloud Infrastructure Costs
```

## Token Usage Tracking

### Metrics Tracked

1. **Input Tokens** - Tokens sent to the AI model
2. **Output Tokens** - Tokens generated by the AI model
3. **Cached Tokens** - Tokens served from cache
4. **Total Tokens** - Sum of all tokens
5. **Average Tokens per Request** - Efficiency metric
6. **Cache Hit Rate** - Percentage of requests served from cache

### Real-Time Monitoring

- **Active Agents** - Number of agents currently executing
- **Tokens Last Hour** - Token consumption in the last hour
- **Tokens Last Day** - Token consumption in the last 24 hours
- **Estimated Daily Cost** - Projected daily cost based on usage
- **Top Consumers** - Agents with highest token usage

1. **Threshold Exceeded** - Budget limit reached

3. **Budget Warning** - Approaching budget limit

## Cost Optimization

### Automatic Recommendations

The system provides optimization suggestions:

1. **Caching** - Enable response caching for similar queries
   - **Potential Savings:** Up to 20% of token costs

2. **Prompt Optimization** - Reduce average token usage per request
   - **Potential Savings:** Up to 15% of token costs

3. **Agent Deactivation** - Deactivate low-usage agents
   - **Potential Savings:** $10+ per inactive agent

4. **Model Selection** - Use faster models for non-critical tasks
   - **Potential Savings:** Up to 10% of token costs

5. **Batching** - Batch similar requests to reduce overhead
   - **Potential Savings:** Up to 5% of token costs

### Efficiency Metrics

- **Cache Hit Rate** - Target: >20%
- **Average Response Time** - Target: <3 seconds
- **Success Rate** - Target: >95%
- **Average Tokens per Request** - Target: <5,000

## API Usage Examples

### Recording Agent Execution

```typescript
import { agentCostTrackingService } from './backend/services/agent-cost-tracking-service';

const metrics = await agentCostTrackingService.recordAgentExecution({
  agentId: 'agent-123',
  agentName: 'Customer Support Agent',
  departmentId: 'customer-experience',
  departmentName: 'Customer Experience',
  companyId: 'company-456',
  tokenUsage: {
    inputTokens: 1500,
    outputTokens: 800,
    totalTokens: 2300,
    cachedTokens: 200,
  },
  executionTime: 2500, // milliseconds
  timestamp: new Date(),
  tier: 'premium',
});

console.log('Total cost:', metrics.totalCost); // $0.00345
```

### Getting Token Analytics

```typescript
import { tokenUsageMonitoringService } from './backend/services/token-usage-monitoring-service';

const analytics = tokenUsageMonitoringService.getTokenUsageAnalytics(
  'company-456',
  'daily'
);

console.log('Total tokens:', analytics.totalTokens);
console.log('Estimated cost:', analytics.estimatedCost);
console.log('Cache hit rate:', analytics.cacheHitRate);
console.log('Trend:', analytics.trend);
```

### Setting Budget

```typescript
const budget = tokenUsageMonitoringService.setTokenBudget({
  companyId: 'company-456',
  budgetId: 'budget-789',
  monthlyTokenLimit: 10000000, // 10M tokens
  monthlyCostLimit: 5000, // $5,000
  alertThresholds: {
    warning: 70,
    critical: 90,
  },
  periodStart: new Date(),
  periodEnd: new Date(Date.now() + 30 * 24 * 60 * 60 * 1000),
});
```

### Getting Cost Estimates

```typescript
const estimate = agentCostTrackingService.estimateMonthlyCost(
  'company-456',
  ['customer-experience', 'sales-revenue'],
  new Map([['customer-experience', 10], ['sales-revenue', 8]]),
  5000, // estimated daily tokens per agent
  'premium'
);

console.log('Estimated monthly cost:', estimate.estimatedMonthlyCost);
console.log('Breakdown:', estimate.breakdown);
```

## Frequently Asked Questions

### Q: How are tokens counted?
A: Tokens are counted for both input (prompts) and output (responses). 1,000 tokens ≈ 750 words.

### Q: Can I change my pricing tier?
A: Yes, you can upgrade or downgrade your tier at any time. Changes take effect at the start of the next billing cycle.

### Q: What happens if I exceed my budget?
A: You'll receive alerts at 70% and 90% of your budget. At 100%, agents will be paused until you increase the budget or reduce usage.

### Q: Are there any hidden fees?
A: No. All costs are transparent: base fee, department costs, token costs, and infrastructure costs.

### Q: Can I set per-department budgets?
A: Yes, you can set budgets at the company, department, or agent level.

### Q: How accurate are cost estimates?
A: Estimates are based on historical usage patterns. Actual costs may vary based on real-time usage.

### Q: Is my data secure?
A: Yes, all data is encrypted at rest and in transit. We comply with SOC 2, GDPR, and HIPAA standards.
