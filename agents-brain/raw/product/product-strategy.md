# Product Management Knowledge Base

## Product Development Framework

### Discovery Phase (2–4 weeks)
1. **Problem Validation**
   - Customer interviews (minimum 5 per persona)
   - Market research: TAM, SAM, SOM analysis
   - Competitive analysis: feature matrix + positioning map
   - Document in PRD (Product Requirements Document)

2. **Solution Exploration**
   - Wireframes (low-fidelity)
   - User story mapping session
   - Technical feasibility review with Engineering
   - ROI estimation

### Definition Phase (1–2 weeks)
- PRD finalized and approved
- Design specs (high-fidelity mockups)
- Technical design doc
- Sprint plan with story points

### Delivery Phase (2–8 weeks depending on scope)
- Two-week sprints
- Daily standups
- Sprint review + retrospective
- Demo to stakeholders at sprint end

### Launch Phase
1. Beta release to 5% of users
2. Monitor error rates, usage, feedback for 72 hours
3. Gradual rollout: 5% → 25% → 50% → 100%
4. Marketing launch coordinated with Product
5. Success metrics tracked for 30 days post-launch

## Prioritization Framework (RICE)

Score = (Reach × Impact × Confidence) / Effort

| Factor | Scale |
|---|---|
| Reach | Number of customers affected (1–10,000) |
| Impact | 3 = massive, 2 = high, 1 = medium, 0.5 = low |
| Confidence | 100% = high, 80% = medium, 50% = low |
| Effort | Person-months (1–12) |

**Threshold**: Score > 50 = Priority queue. Score 20–50 = Next quarter. Score < 20 = Backlog.

## Roadmap Planning

### Annual Themes (set at start of fiscal year)
- 3–5 strategic themes maximum
- Each theme ties to company OKRs
- Reviewed quarterly

### Quarterly Roadmap
- Now (current quarter): Committed
- Next (next quarter): High confidence
- Later (2+ quarters out): Directional

### Release Cadence
- **Major releases**: Quarterly (with marketing)
- **Minor releases**: Monthly
- **Patches**: As needed (hotfixes within 24h)

## Success Metrics by Feature Type

| Feature Type | Primary Metric | Target |
|---|---|---|
| Acquisition | Signup conversion rate | +20% |
| Activation | Time to first value | ≤7 days |
| Engagement | DAU/MAU ratio | ≥40% |
| Retention | Week-4 retention | ≥60% |
| Monetization | ARPU growth | +10% QoQ |
| Referral | Viral coefficient | >0.5 |

## User Research Repository

### Interview Templates
- **Discovery**: "Walk me through how you currently solve X..."
- **Usability**: "Complete this task while thinking aloud"
- **Satisfaction**: "What's the one thing you'd change?"
- **Churn**: "What was the moment you decided to leave?"

### Persona Library
Maintain 3–5 core personas with:
- Demographics
- Goals
- Pain points
- Current solutions
- Quotes from real interviews

Update personas annually or when significant market shift occurs.
