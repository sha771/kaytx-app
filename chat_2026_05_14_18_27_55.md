Layer 2: Leadership (Strategy)
Work Type: Strategy
Flow: Vision

Layer 3: Simulation (Testing)
Work Type: Testing
Flow: Test
Use Case: Test before doing
Simulates scenarios to validate approaches before execution

Layer 4: Intelligence (Analysis)
Work Type: Analysis
Flow: Predict

Layer 5: Memory (Learning)
Work Type: Learning
Flow: Remember

Layer 6: Translation (Communication)
Work Type: Communication
Flow: Bridge

Layer 7: Command (Control)

Layer 9: Execution (Operations)
Work Type: Operations

Work Type: Execution
Flow: Do tasks

Work Type: Feedback
Flow: Review & show
