- Zoom: 75%

# Recording software
- OBS Studio (free) or Camtasia (paid)
- Capture: Browser window
- Frame rate: 60fps

## Production Notes

### Voice Style
- Confident, visionary, energetic
- Pace: Moderate with strategic pauses
- Tone: Professional yet approachable
- Emphasis: Convenience and control

### Visual Style
- Clean, modern, minimal
- Smooth transitions between platforms
- Platform-specific branding (WhatsApp green, Slack purple, Telegram blue, X black, Reddit orange)
- Typography: Bold, readable, consistent

### Music
- Upbeat, modern tech background music
- Volume: Low, doesn't compete with voiceover
- Mood: Inspiring, confident, connected

### Graphics
- Platform icons with brand colors
- Animated message bubbles
- Progress indicators and checkmarks
- Cross-platform sync animations
