## Pre-Recording Setup (Do This First)

### Terminal Commands
```powershell
cd c:\Users\shaida\Desktop\kaytx-full-app
npx expo start --web
```

### Browser Setup
1. Open Chrome/Edge
2. Navigate to `http://localhost:8081`
3. Press F12 (DevTools)
4. Press Ctrl+Shift+M (Toggle Device Toolbar)
5. Set resolution to 1920 x 1080
6. Zoom to 75%

### Recording Software (OBS)
- Start OBS
- Add Source: Window Capture (select browser window)
- Settings: 1920x1080, 60fps
- Output: MKV format
- Start Recording Hotkey: Set to F9 (easy access)

## Quick Troubleshooting

### App won't load?
```bash
cd c:\Users\shaida\Desktop\kaytx-full-app
npm install
npx expo start --web --clear
```

### Recording is choppy?
- Lower OBS settings to 30fps
- Close other applications
- Record to SSD, not HDD

### Audio has echo?
- Move to smaller room
- Add soft furnishings
- Speak closer to mic
- Use noise reduction in post

### Screens look too small?
- Increase browser zoom to 80-85%
- Ensure 1920x1080 resolution
- Check OBS capture region
