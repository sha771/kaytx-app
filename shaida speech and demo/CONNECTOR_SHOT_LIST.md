## Technical Recording Notes

### Mouse Movement Cues

| Time | Action | Movement Style |
|------|--------|----------------|
| 0:05 | Type WhatsApp command | Smooth typing, deliberate |
| 0:15 | Tap approval button | Precise tap, highlight |
| 0:25 | Type Slack command | Quick, confident |
| 0:35 | Select slash option | Smooth selection |
| 0:45 | Tap Telegram button | One-tap action |
| 0:55 | Type X command | Natural typing |
| 1:05 | Type Reddit command | Clear, readable |
| 1:45 | Navigate to Hub | Smooth navigation |
| 2:05 | Click tabs | Precise clicks |

### Text Overlay Timing

All text overlays should:
- Fade in over 0.5 seconds
- Hold for 2-3 seconds
- Fade out over 0.5 seconds
- Use consistent position (lower third)

### Music Cues

- **0:00-0:10:** Music fade in
- **0:10-1:00:** Energetic, building (platform demos)
- **1:00-1:45:** Confident, professional (Hub + Security)
- **1:45-2:25:** Inspiring, motivating (Use cases)
- **2:25-3:00:** Strong finish, fade out

## Recording Day Checklist

Before you start:
- [ ] All platform accounts ready (WhatsApp, Slack, Telegram, X, Reddit)
- [ ] KAYTX bot installed on all platforms
- [ ] Test commands prepared and working
- [ ] Connector dashboard accessible
- [ ] No notifications will interrupt

- [ ] Water bottle nearby

## Platform-Specific Notes

### WhatsApp
- Use WhatsApp Web for recording
- Ensure bot is verified and trusted
- Have test contacts ready
- Prepare sample commands in advance

### Slack
- Use test workspace
- Create dedicated #kaytx-ai channel
- Install KAYTX app/bot
- Prepare slash commands
- Have team members for reactions (optional)

### Telegram
- Use Telegram Web for recording
- Bot should be verified
- Prepare inline keyboard layouts
- Have sample files ready for export

### X/Twitter
- Use X DM interface
- Bot should be verified
- Prepare multi-platform post drafts
- Have analytics data ready

### Reddit
- Use Reddit chat or mod tools
- Bot should have appropriate permissions
- Prepare test subreddit (r/startups or similar)
- Have sample posts ready for monitoring
