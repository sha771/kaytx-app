# Browser settings
- Chrome or Edge
- Resolution: 1920x1080
- Zoom: 75%
- Device mode: Responsive

# Recording software
- OBS Studio (free) or Camtasia (paid)
- Capture: Browser window
- Frame rate: 60fps
- Output: MKV (remux to MP4)

## Recording Tips

1. **Smooth scrolling** - Enable smooth scroll in browser settings
2. **Click highlighting** - Use OBS click effects or Camtasia cursor effects
3. **Timing** - Practice the flow before recording
4. **Clean environment** - Close all other apps, hide bookmarks
5. **Consistent zoom** - Keep zoom at 75% throughout
