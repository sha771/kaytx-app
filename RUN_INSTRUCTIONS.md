# Kaytx Full App - Run Instructions

## Backend (Running)
```
npm run backend
```
Health: http://localhost:3000/health

## Frontend Web Dev
```
set PUPPETEER_SKIP_DOWNLOAD=true
npm run start-web-dev
```

## TypeScript Typecheck
```
npm run typecheck
```

## Lint
```
npm run lint
```

## Full Start
```
npm run start
```

**Note**: Large monorepo - typecheck/lint may take time. All errors fixed.
