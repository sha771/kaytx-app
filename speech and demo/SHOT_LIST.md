## Technical Recording Notes

### Mouse Movement Cues

| Time | Action | Movement Style |
|------|--------|----------------|
| 0:35 | Open sidebar | Smooth click, brief pause |
| 0:45 | Scroll sidebar | Slow, steady scroll |
| 0:55 | Click CEO card | Precise click, highlight |
| 1:05 | Navigate back | Top-left back button |
| 1:15 | Hover cards | Slow, deliberate hover |
| 1:40 | Scroll dashboard | Smooth vertical scroll |

### Text Overlay Timing

All text overlays should:
- Fade in over 0.5 seconds
- Hold for 2-3 seconds
- Fade out over 0.5 seconds
- Use consistent position (lower third or center)

### Music Cues

- **0:00-0:10:** Music fade in
- **0:10-0:30:** Slightly subdued (serious tone)
- **0:30-1:50:** Upbeat, building energy
- **1:50-2:10:** Confident, trustworthy
- **2:10-2:30:** Exciting, motivating
- **2:30-2:45:** Strong finish, fade out

## Recording Day Checklist

Before you start:
- [ ] App is running smoothly
- [ ] Test data is populated (realistic numbers)
- [ ] All screens load without errors
- [ ] Sidebar is fully expanded for shots
- [ ] No notifications or popups will interrupt
- [ ] Recording software tested
- [ ] Voiceover script printed/handy
- [ ] Water bottle nearby
- [ ] Phone on silent
